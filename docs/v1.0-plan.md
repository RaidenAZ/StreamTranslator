# StreamTranslator V1.0 Plan

本文档定义 V1.0 的范围、完成标准、测试策略和后续版本方向。

## V1.0 Scope

V1.0 目标是做出可用、可诊断、可测试的实时 ASR 字幕主链路。

包含：

- WPF 主窗口。
- 悬浮字幕窗。
- 指定输出设备 WASAPI loopback 捕获。
- 音频统一转换为 16kHz mono PCM16。
- Silero ONNX VAD。
- 可配置尾静音断句等待，V1.0 固定模式默认 300ms；V1.1 默认切换为均衡自适应模式，初始端点为 400ms。
- soft/hard max 切片和 overlap。
- 本地确定性文本去重。
- Python worker 子进程。
- stdin/stdout JSON 协议。
- MiMo ASR 调用。
- ASR 队列、有限并发和重排序。
- 字幕历史保存。
- 复制字幕文本。
- 日志和诊断信息。
- 诊断模式。
- 离线音频分段 CLI。
- 发布版绿色便携，内置 Python worker exe。

不包含：

- 翻译字幕。
- 滚动 interim ASR 默认启用。
- 按应用/窗口音频捕获。
- 字幕文件导出。
- 托盘常驻。
- 云端账号系统。
- 自动更新。
- 跨平台支持。

## Definition Of Done

V1.0 完成标准：

1. 能选择输出设备并捕获系统播放声音。
2. 音频统一转为 16kHz mono PCM16。
3. Silero ONNX VAD 能加载并输出 speech probability。
4. `SpeechSegmenter` 在 V1.0 固定模式能按 300ms 默认尾静音切段，参数可调；V1.1 由自适应端点控制器提供有效端点。
5. 连续说话有 soft/hard max 和 overlap。
6. C# 能启动/停止 Python worker，退出主窗口能清理 worker。
7. Python worker 能通过 OpenAI SDK 调 MiMo ASR。
8. C# 和 Python 通过 stdin/stdout JSON 通信。
9. ASR 结果能显示到悬浮字幕窗。
10. 悬浮窗支持置顶、拖动、锁定、点击穿透、字号、透明度、行数设置。
11. 主窗口使用主页、字幕历史、设置、关于四项导航；音频、服务和悬浮窗参数收敛到设置页。
12. 设置保存到 exe 同目录 `data/settings.json`，明文保存 API Key。
13. 字幕历史保存到 `data/subtitles/*.jsonl`。
14. 支持复制选中、最近 N 条、当天全部字幕。
15. 日志写入 `data/logs`，并提供打开目录、复制诊断信息。
16. 诊断模式默认关闭，开启后保存 segment WAV、VAD timeline、session JSON 和 metrics JSON。
17. 离线音频分段 CLI 可跑同一套 VAD/segment 管线。
18. 自动重试一次，错误状态分层显示。
19. 单元、协议、worker、音频样本回归测试和 Windows TTS VAD smoke 可运行。
20. 发布版绿色便携，用户不需要安装 Python。

## Suggested Milestones

### M1: Solution And Core Models

目标：

- `AppSettings`
- `WorkerRequest` / `WorkerResponse`
- `TextDeduplicator`

目标：

- 完成音频标准格式和分段核心逻辑。

输出：

- `StreamTranslator.Audio`
- `AudioFrame`
- `IVadEngine`
- `SpeechSegmenter`

- Segmenter 单元测试

### M3: Silero ONNX VAD

目标：

- 接入 ONNX Runtime。
- 能加载模型并对 16kHz PCM16 帧输出 speech probability。

输出：

- `SileroOnnxVadEngine`
- 模型加载错误处理
- VAD 基础集成测试

### M4: Python Worker Protocol

目标：

### M5: ASR Queue And Subtitle Timeline

输出：

### M6: WPF Main Window And Floating Window

目标：

- 实现主窗口页面和悬浮字幕窗。

- 悬浮窗设置页

### M7: Diagnostics And Regression

目标：

- 完成诊断模式和离线音频分段 CLI。

输出：

## Testing Strategy

V1.0 测试不是可选项。测试结果要直接指导 V1.0 后的 fix 和 feature。

### Unit Tests

重点：

- `SpeechSegmenter`
- `TextDeduplicator`
- Settings read/write/defaults
- Subtitle timeline
- Reorder buffer

`SpeechSegmenter` 场景：

- 300ms 尾静音正确结束。
- `MinSegmentMs` 防止过短切片。
- soft max 开始寻找自然断点。
- hard max 强制切片。
- overlap 时间正确。
- 连续说话不会无限增长。

`TextDeduplicator` 场景：

- 中文 suffix/prefix 去重。
- 英文词级去重。
- 无重叠不合并。
- 过短重叠不合并。
- 只处理最近 1-2 条 final 字幕。

### Protocol Tests

重点：

- C# 请求和 Python 响应 id 匹配。
- sequence 匹配。
- timeout。
- worker crash。
- stderr logging。
- shutdown。

### Python Worker Tests

Python worker 使用 fake ASR client 测试：

- transcribe ok。
- transcribe error。
- timeout。
- 401/403。
- 429。
- invalid request。

真实 ASR API 不作为默认 CI 测试，避免成本、网络和密钥依赖。

### Audio Sample Regression Tests

建立固定音频样本集，使用离线 CLI 跑完整分段链路。

输出：

- segment JSON
- VAD timeline JSONL
- segment WAV
- metrics JSON

建议统计指标：

- total audio duration
- speech duration
- segment count
- average segment duration
- too short segment count
- hard cut count
- silence cut count
- overlap count
- empty segment count
- dedup hit rate
- ASR latency if enabled
- ASR error rate if enabled

golden 文件只用于检测明显回归，不要求每个时间戳完全固定到毫秒级。允许设置合理 tolerance。

### Manual Acceptance Checklist

必须手工验证：

- Windows 10 x64 启动。
- Windows 11 x64 启动。
- 选择扬声器捕获。
- 选择耳机捕获。
- 跟随默认设备。
- 设备断开后状态正确。
- 悬浮窗置顶。
- 悬浮窗锁定后点击穿透。
- 快捷键启停/隐藏/锁定。
- 关闭主窗口后 worker 被清理。
- API Key 错误时状态显示正确。
- 真实 MiMo ASR 请求可用。
- 诊断模式默认关闭。
- 诊断模式开启后生成预期文件。

## Roadmap After V1.0

### V1.1

目标：目标驱动的自适应尾静音和字幕层修订。

范围：

- `低延迟 / 均衡 / 句子完整 / 固定值` 四种断句策略。
- 默认强制启用 `均衡` 自适应。
- 第一版只动态调整 `EndSilenceMs`。
- 最近 8 次停顿、15 秒样本时效、P75 加安全余量。
- 疑似误切驱动的快速上调和字幕层合并。
- 最多 3 段、最长 12 秒的有限链式 revision。
- append-only 历史修订事件。
- 动态端点、误切率、合并率和 ASR 调用次数 metrics。

开启条件：

- 当前 V1.0 final ASR 主链路、Silero ONNX、文本去重和历史保存稳定。
- 固定值模式能够保持 V1.0 分段行为。
- 有离线音频与 Windows TTS smoke 支撑回归。

完整规格见 [v1.1-adaptive-vad.md](v1.1-adaptive-vad.md)。

### V1.2

目标：在 V1.1 自适应端点稳定后，增加可选的实时双语翻译字幕。

范围：

- 独立 translation worker。
- OpenAI Chat Completions compatible 远程 API 和本地模型服务。
- 多个模型配置和单个活动配置。
- 中、英、德、法、日五种目标语言。
- revision-aware 非流式翻译。
- 双语悬浮窗和 append-only 翻译历史。
- 翻译队列、背压、熔断、诊断和离线评估。

完整规格：

- [v1.2-translation.md](v1.2-translation.md)
- [v1.2-translation-protocol.md](v1.2-translation-protocol.md)
- [v1.2-translation-test-plan.md](v1.2-translation-test-plan.md)

### V1.3

目标：在 V1.2 翻译链路稳定后，重新评估 rolling interim ASR。

可评估：

- rolling interim chunk，默认关闭。
- interim API 调用次数、成本、失败率和限流影响。
- ASR interim 与 translation revision 的状态模型。
- 更精细的字幕修正策略。

## Open Questions

以下问题留到实现或 V1.0 后再定：

- 是否需要 WebRTC VAD fallback。
- 是否需要 Energy VAD fallback。
- 是否需要按应用捕获。
- 是否需要托盘常驻。
- 是否需要字幕 TXT/SRT 导出。
- 是否需要加密 API Key。
- 是否需要 LLM 做回放阶段的字幕整理。
