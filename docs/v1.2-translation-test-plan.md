# StreamTranslator V1.2 Translation Test And Acceptance Plan

状态：Accepted，等待实施

更新时间：2026-07-14

本文档定义 V1.2 翻译字幕的自动测试、真实 API 验收、UI smoke、诊断输出和发布门槛。实现规格见 [v1.2-translation.md](v1.2-translation.md)，worker 契约见 [v1.2-translation-protocol.md](v1.2-translation-protocol.md)。

## Test Principles

- V1.2 测试必须覆盖远程 API 和本地 OpenAI-compatible 协议形状，但真实发布门槛只绑定 DeepSeek 远程参考链路。
- 默认自动测试不访问真实网络、不读取真实 API Key、不产生费用。
- 模型翻译结果不使用字符串精确匹配作为主要质量判定。
- 协议、调度、历史和 UI 使用确定性测试；语义质量使用人工标注。
- V1.0/V1.1 音频、VAD、ASR 和 subtitle revision 测试必须继续通过。
- 所有时间相关逻辑使用可注入 clock，禁止依赖真实 sleep 完成单元测试。

## Test Layers

```text
.NET unit tests
  -> C# integration tests with fake worker
  -> Python unit tests
  -> Python fake OpenAI HTTP integration
  -> C#/Python protocol integration
  -> WPF UI smoke
  -> offline translation evaluation
  -> real DeepSeek acceptance
  -> portable package smoke
```

## .NET Unit Tests

### Settings And Migration

覆盖：

- 新配置 schema version 3。
- 翻译默认关闭。
- 目标语言默认 `zh-Hans`。
- 配置列表为空且 active profile 为 null。
- 所有旧配置的悬浮窗字号强制迁移为 18。
- 旧 `MaxLines` 迁移为 `MaxSubtitleItems` 并限制在 1-3。
- 迁移保留音频、VAD、ASR、快捷键和诊断设置。
- profile ID 唯一且稳定。
- active profile 不存在时翻译按关闭处理。
- 运行中修改翻译配置被拒绝。

### Profile Validation

覆盖：

- name、Base URL、model 必填。
- timeout 只能是 3000-30000ms。
- concurrency 只能是 1-4。
- Remote 只允许 HTTPS。
- Local 允许 HTTP 和 HTTPS。
- URL query、fragment、userinfo 和完整 `/chat/completions` 路径校验。
- Base URL 有无 trailing slash 时 Preview 一致。
- 不自动补 `/v1`。
- 公网/域名建议 Remote，loopback/private IP 建议 Local。
- 用户可以覆盖自动建议。
- 配置关键字段变化使 validation fingerprint 失效。
- 模型名只做非空验证，不调用 `/models`。

### Extra Body Templates

覆盖：

- Standard 产生空 object。
- DeepSeek 产生 `thinking.type=disabled`。
- QwenVllm 产生 `chat_template_kwargs.enable_thinking=false`。
- Custom 只接受 object。
- Custom 最大 16KB。
- 禁止所有保留字段。
- JSON 解析错误包含行列信息。
- 模板 JSON Preview 与实际发送内容一致。

### Source Language Decision

明确语言：

- `zh -> zh-Hans` 跳过。
- `en -> en` 跳过。
- `zh -> en` 不跳过。
- `en -> zh-Hans` 不跳过。

`auto` 风险集：

- 纯中文长句。
- 纯英文长句。
- 中英混合句。
- 只有数字和时间。
- `F1`、`iPhone`、`WWDC` 等短专有名词。
- 中文中包含英文产品名。
- 英文中包含中文人名。
- 极短内容：`OK`、`好`、`Go`。
- 标点或空白文本。

断言：

- 高置信同语言才跳过。
- 未知文本必须提交模型。
- 错误隐藏有效译文用例为 0。

### Translation Context

覆盖：

- 最多 3 组。
- 最大年龄 30 秒。
- 超龄项按时间移除。
- revision 替换同 group context。
- 新会话、停止会话和目标语言变更清空。
- 上一配置译文不进入新模型会话。
- 缺少译文时允许 source-only context。
- 当前 source 不被放入 context 数组重复发送。

### Translation Task Identity

覆盖：

- task key 包含 group、source revision、target 和 profile。
- 同 task key 去重。
- 不同 revision 必须产生新任务。
- 相同文本、不同 group 不缓存、不复用。
- target 或 profile 不同不得复用。

### Queue And Backpressure

使用 fake clock 覆盖：

- 默认容量 8。
- 第 9 条任务触发最旧可丢弃任务淘汰。
- 等待超过 10 秒任务过期。
- 旧 revision 优先丢弃。
- 已离开悬浮窗的任务优先级低于仍可见任务。
- 当前最新任务不能被旧任务阻塞。
- dropped task 保留原文并记录 metrics。
- 正常平均每 2 秒一条输入不触发丢弃。
- 并发范围 1-4 生效。
- 结果乱序不改变 source 顺序。

### Revision Coordination

覆盖：

- 初始字幕立即创建翻译任务。
- source revision 立即清空物化译文。
- 未发送旧任务取消。
- 已发送旧结果返回后判为 stale。
- 最新 revision 译文可以物化。
- 旧 revision 永远不能覆盖新 source。
- revision 翻译失败时不恢复旧译文。
- MiMo ASR 调用数不因翻译 revision 增加。

### Retry And Circuit Breaker

覆盖：

- transient error 最多重试一次。
- retry 前任务已过期时不重试。
- authentication、model、configuration、protocol 不重试。
- 连续 3 个 transient terminal failure 打开熔断。
- 初始冷却 10 秒。
- 探测成功恢复。
- 探测失败增加冷却，最大 60 秒。
- 新会话清空熔断。
- 熔断期间 source 字幕继续工作。

### Worker Recovery

覆盖：

- 首次 worker crash 自动重启。
- in-flight task 不重新提交。
- 未发送且未过期任务在恢复后继续。
- 第二次 crash 停止本会话翻译。
- ASR runtime 不因 translation worker crash 停止。
- 关闭主窗口清理 translation worker process tree。

### Stop Drain

覆盖：

- 停止后不产生新翻译任务。
- 3 秒内完成结果写入历史。
- 3 秒后取消剩余任务。
- 取消结果不能晚到更新 UI。
- 主窗口关闭不被远程请求长期阻塞。

### Translation History Materialization

覆盖：

- source-only 旧历史兼容。
- translation_result 匹配当前 source revision。
- 多个 translation_result 只使用最新成功项。
- 旧 source revision 译文被忽略。
- translation_status 不覆盖成功译文。
- target language 不显示标签。
- GeneratedAt 继续使用 source 时间。
- 混合目标语言历史仍不显示标签。
- 历史读取遇到损坏 translation event 时跳过并继续。

### Bilingual Copy

覆盖：

- 选中条目双语复制。
- 最近 10 条双语复制。
- 当天全部双语复制。
- source-only 条目不产生空白译文行。
- 时间只输出一次。
- 长文本保持换行并无水平滚动依赖。

## Python Unit Tests

### Prompt Builder

覆盖：

- system prompt snapshot 与 `translation-v1` 绑定。
- 五种目标语言名称和代码映射。
- source language `zh`、`en`、`auto`。
- context 为 0-3 项。
- JSON serializer 正确转义引号、换行、反斜杠和类似 Prompt injection 的字幕。
- 当前字幕只出现于 `currentSubtitle`。
- Prompt 不包含 API Key、Base URL 或 profile name。
- 不发送 temperature、top-p、top-k、tools 或 response format。

### OpenAI Request Construction

覆盖：

- Base URL 无 `/v1` 时请求 `/chat/completions`。
- Base URL 有 `/v1` 时请求 `/v1/chat/completions`。
- `max_retries=0`。
- timeout 使用 profile 值。
- API Key 为空时本地 fake server 仍可调用。
- Standard、DeepSeek、QwenVllm、Custom extra body。
- 非流式请求。
- 模型名原样传递。

### Response Normalization

覆盖：

- 普通字符串 content。
- 文本 content parts。
- reasoning_content 被忽略并产生 warning。
- 完整 think block 被移除。
- 未闭合 think block 失败。
- 完整 Markdown fence 被移除。
- 普通引号和冒号不被误删。
- 空 content 失败。
- 只有 reasoning 失败。
- UTF-8 超过 8KB 失败。
- suspicious length 只 warning，不直接失败。

### Error Classification

覆盖：

- configuration。
- authentication 401/403。
- model_not_found。
- endpoint_not_found 404。
- connection refused、DNS 和 TLS。
- timeout。
- rate_limit 429。
- server 5xx。
- protocol malformed JSON / missing choices。
- invalid_response。
- unknown fallback。

断言每种错误的 `retryable` 与协议文档一致。

### JSONL Protocol

覆盖：

- startup ready。
- configure 成功和失败。
- configure 前 translate 被拒绝。
- ping configured 状态。
- bounded concurrency。
- 乱序响应 id 匹配。
- shutdown。
- malformed request 不终止 worker。
- stdout 只包含 JSONL，traceback 只进入 stderr。
- terminal response 恰好一次。
- API Key 不出现在 stdout 和 stderr fixture。

## Fake OpenAI-Compatible HTTP Server

默认自动测试启动本地 fake server，提供可编程响应：

- 正常 Chat Completions。
- 延迟响应。
- 乱序响应。
- 401、403、404、429、500、502、503。
- connection reset。
- invalid JSON。
- 缺少 choices/message/content。
- reasoning + content。
- think block。
- 空 content。
- 超大 content。
- 拒绝特定 extraBody。
- 记录收到的 path、model、messages 和 extra body。

fake server 测试断言：

- 实际 URL 与 UI Preview 一致。
- Prompt 结构和上下文正确。
- 禁止字段未被覆盖。
- retry 次数没有被 OpenAI SDK 隐式放大。
- 超时和取消不会留下未完成协议任务。

## C# / Python Integration Tests

使用真实 Python worker 和 fake HTTP server：

- C# 启动、configure、translate、shutdown 完整链路。
- API Key 通过 stdin configure，不出现在 process arguments。
- 并发 2 时乱序结果正确关联。
- worker crash 后 C# 只重启一次。
- stale revision 返回不更新 history/UI model。
- 停止字幕最多等待 3 秒。
- translation failure 不停止 fake ASR runtime。
- app close 清理 worker。

## Offline Evaluation Script

建议输入：

```json
{"id":"en-001","sourceLanguage":"en","sourceText":"The live stream starts at 9:30.","targetLanguage":"zh-Hans"}
{"id":"zh-001","sourceLanguage":"zh","sourceText":"赛车将在十分钟后重新开始。","targetLanguage":"en"}
```

可选 revision fixture：

```json
{"id":"rev-001","utteranceGroupId":"g-1","sourceRevision":1,"sourceText":"The driver is","targetLanguage":"zh-Hans"}
{"id":"rev-002","utteranceGroupId":"g-1","sourceRevision":2,"sourceText":"The driver is leading the race.","targetLanguage":"zh-Hans"}
```

输出目录：

```text
data/translation-evaluation/YYYYMMDD-HHmmss/
  requests.jsonl
  results.jsonl
  metrics.json
  report.md
```

脚本要求：

- 默认拒绝真实网络请求。
- 只有 `-AllowLiveApi` 才允许调用远程服务。
- 输出不包含 API Key。
- 支持按 profile、目标语言和 Prompt 版本记录结果。
- 支持失败后继续处理剩余样本。
- 返回非零退出码表示自动门槛失败。

API Key 的最终提供方式仍是待决项，脚本实现前必须补充决策。

## Real DeepSeek V4 Flash Acceptance

真实 DeepSeek V4 Flash 测试不进入默认 test suite。发布前显式运行，并保存脱敏结果。实际 API 模型标识由测试人员手动填写，不硬编码到应用。

### Environment Record

记录：

- 日期和网络区域。
- Base URL 脱敏值。
- 手动填写的模型名。
- DeepSeek request compatibility 模板。
- Prompt 版本。
- 目标语言。
- 并发和 timeout。
- 样本集版本。

### Chinese And English Corpus

至少：

- 英译中 50 条。
- 中译英 50 条。

场景覆盖：

- 普通直播对话。
- 体育和游戏解说。
- 产品发布与技术术语。
- 新闻播报。
- 数字、比分、价格、时间和单位。
- 人名、队名、产品名。
- 口语、重复、犹豫和粗俗表达。
- VAD 暂时切断的不完整句。
- revision 后的完整句。
- Prompt injection 样式原文。
- 中英混合和代码切换。

### Human Labels

每条译文标记：

- `pass`：可直接作为实时字幕使用。
- `minor`：措辞不自然但不影响理解。
- `major`：漏译、反义、关系错误、数字错误、无依据扩写、解释或内容丢失。

### Initial Quality Gates

- major error rate < 5%。
- 数字、时间、单位错误率 < 2%。
- 解释、Markdown、思考文本或空译文 < 1%。
- revision stale overwrite = 0。
- same-language false skip = 0。

### German, French And Japanese Smoke

每种语言至少一条真实请求：

- 返回非空译文。
- 目标语言明显正确。
- 无协议错误和多余 reasoning 输出。

不做完整人工质量矩阵。

## Latency Acceptance

DeepSeek 参考链路首轮目标：

- translation request P50 <= 1.5 秒。
- translation request P95 <= 3 秒。
- C# queue + IPC + UI update P95 <= 100ms。
- 平均每 2 秒一条输入不触发背压丢弃。
- revision request 使用相同统计口径。

这些数值是初始目标。若真实服务稳定超过门槛，必须保存数据并重新决策，不能仅修改测试使其通过。

## Soak Test

至少一次 1-2 小时真实直播会话：

- 翻译开启，目标中文或英语。
- DeepSeek 远程配置。
- 记录进程内存、队列峰值、请求数、失败率、熔断和 worker 重启。
- 验证 translation history 持续追加。
- 验证长时间运行后 UI 更新仍在 Dispatcher 预算内。
- 模拟短暂断网和恢复。
- 模拟 translation worker crash 一次。
- 停止后验证 3 秒 drain 和进程清理。

## Portable Package Smoke

最终发布包必须验证：

- 包含 `worker/translation_worker.exe`。
- 不要求用户安装 Python。
- 不包含 API Key、测试 Profile、测试历史或 debug-translation 数据。
- 首次启动 translation 默认关闭。
- 悬浮窗字号为 18。
- 添加配置、测试连接、开始字幕和双语显示可运行。
- translation worker 与 asr worker 分别启动和退出。
- 关闭主窗口后没有残留 worker process。

## Known Risks To Track

1. `auto` 同语言判断可能在中英混合和短专有名词上误判。
2. 原文先显示、译文后补充可能造成阅读割裂。
3. 译文预留高度和 revision 清空可能造成视觉闪烁。
4. 队列 8 条和 10 秒过期值可能不适配所有模型。
5. DeepSeek P50/P95 初始门槛可能受网络区域影响。
6. Qwen thinking 参数取决于部署后端，不能仅按模型名推断。
7. 本地模型仅手工测试，不作为 V1.2 发布阻塞项。
8. 离线评估脚本的 API Key 提供方式尚未确认。
